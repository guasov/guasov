## Proyecto

**[Invosaur](https://github.com/guasov/invosaur-proyecto)**: aplicación web en producción para gestorías. Lee facturas con IA, las renombra y prepara su importación en el programa de contabilidad. La llevo de principio a fin: servidor, despliegues, copias de seguridad, seguridad y trato con el cliente.

## Tecnologías

Linux · Docker y Docker Compose · Caddy (proxy inverso y HTTPS) · PostgreSQL · Git y GitHub · cortafuegos · copias de seguridad · agentes de IA (Claude Code)
